# Space Quiz Workshop Demo

A Korean-language space exploration quiz built for a hands-on workshop.

Open `index.html` in a browser. No server, build step, installation, or external dependencies are required.

The quiz includes 10 questions, progress and score tracking, answer explanations, animated feedback, and a results screen with an animated final score and emoji reactions.

Use Tab to navigate and Enter or Space to select. Arrow keys, Home, and End also navigate answer choices. The quiz supports screen readers, system light/dark themes, and reduced-motion preferences.

See `AGENTS.md` for project contribution guidelines.
